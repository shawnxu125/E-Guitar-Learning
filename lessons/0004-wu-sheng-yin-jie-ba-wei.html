🎸 Lesson 4: 五声音阶把位体系

你需要：电吉他 + 20分钟。你会 1-2 个把位？那正好——今天把它们连成体系。

🎯 这节课结束后，你能做到：
  1. 理解 C 大调五声音阶 = A 小调五声音阶（同一批音，不同的"家"）
  2. 把熟悉的 5品把位弹熟、弹出"大调味"
  3. 学会相邻的 8-10品把位，并能在两个把位间穿梭
  4. 知道整个指板怎么被五个把位覆盖（速查表在 这里）

1. 先想通一件事：相对大小调

C 大调五声音阶的音是 C D E G A。A 小调五声音阶的音是 A C D E G。

同一批音！区别只在于你把哪个音当"家"（根音）：

  • 围绕 C 转 → 明亮、开心的大调味（1645 伴奏 solo 用这个感觉）
  • 围绕 A 转 → 忧郁、摇滚的小调味（蓝调 solo 用这个感觉）
💡 实战意义：你练的"Am 五声音阶指型"就是"C 大调五声音阶指型"。指型不用重学，只需要改变你强调的音——solo 时多落在 C 上就是大调味，多落在 A 上就是小调味。

2. 把位 1：5品盒子（你的主战场）

这是你大概率已经会的指型。指板记谱：3-2-1弦 = G-B-e，音名已逐音核对：

e |----5---8---|   A   C
B |----5---8---|   E   G
G |----5---7---|   C   D
D |----5---7---|   G   A
A |----5---7---|   D   E
E |----5---8---|   A   C

C 根音位置（红色记住）：3弦5品、1弦8品、6弦8品（盒子上边缘）。solo 时乐句落在这些音上 = 大调味。

1 上下行：60 BPM 八分音符，从6弦5品爬到1弦8品再爬回来。要求：每个音清晰、时值均匀。
2 根音着陆：随便弹4个音的短句，最后一个音必须是 C（3弦5品或1弦8品）。练10句。
3 跟伴奏：手机搜 "1645 backing track C major"，在盒子里随便弹，句尾落 C。

3. 把位 2：8-10品盒子（今天的新把位）

e |----8---10---|   C   D
B |----8---10---|   G   A
G |----7---9----|   D   E
D |----7---10---|   A   C
A |----7---10---|   E   G
E |----8---10---|   C   D

C 根音位置：1弦8品、4弦10品、6弦8品（盒子下边缘）。注意 1弦8品 这个音两个把位共用——它就是连接点。

1 上下行：同把位1的练法，60 BPM 爬格子。
2 穿梭练习：把位1爬到1弦8品(C) → 不抬手直接进把位2弹1弦10品(D) → 再退回。来回10次。
这就是"纵向把位连接"的种子，以后五个把位都这么串。

4. 整个指板的地图

五声音阶共有 5 个盒子把位，像五块拼图铺满指板。你现在掌握了其中两块（5品区、8-10品区）。剩下三块在 五声音阶把位速查表里，之后每课学一块，不贪多。

▸ 换调怎么办？盒子是活的——整体平移即可。
▸ 6弦根音在几品，盒子就从几品开始：C=8品，D=10品，E=12品，G=3品，A=5品。
▸ 歌手说"这首歌是 A 调"→ 6弦5品开始弹同一套盒子（A小调盒子= C大调盒子的老位置！）。

🧠 快速自测

Q1. C 大调五声音阶和 A 小调五声音阶的关系是：

✓ 都是 C D E G A 五个音，"家"不同而已。
✗ 数一数：C大调五声 = C D E G A；A小调五声 = A C D E G。完全相同。

Q2. 5品盒子里，哪个位置的音是 C（大调根音）？

✓ 3弦5品=C。另外两个C在1弦8品和6弦8品。
✗ 6弦5品=A，2弦5品=E，4弦7品=A。3弦5品才是C。
