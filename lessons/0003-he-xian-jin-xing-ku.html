🎸 Lesson 3: 四大和弦进行

你需要：电吉他 + 20分钟。前置：Lesson 1 级数、Lesson 2 横按与三音和弦。

🎯 这节课结束后，你能做到：
  1. 认出并弹出华语流行四大进行：1645、4536251、卡农、1564
  2. 每个进行都有"横按版"和"三音和弦版"两套弹法
  3. 拿到 进行速查表，任何调都能自己拼出来

为什么是这四个？

流行乐的进行是有限的组合。你已经会了 1645；再学会今天这三个，加上它们的轮转变体，就能覆盖大部分华语流行的主歌+副歌。之后遇到新歌，你的任务不是"学和弦"，而是"认出它是哪个进行"。

⚠️ 关于歌曲例子：下面列的歌是网络分析中常被引用的例子，以你的耳朵为准（学会 Lesson 8 听音扒和弦后你就能自己验证——这也是检验你耳朵的好素材）。

1. 4536251 —— "虐心进行"

华语抒情歌的代名词，常被叫做"虐心进行"。C 大调：

ⅣF
ⅤG
ⅢEm
ⅥAm
ⅡDm
ⅤG
ⅠC

常引用例：《演员》《她说》《告白气球》《雨天》的副歌段落。

和弦FGEmAmDmGC
横按 E型 1品E型 3品开放Em
(或Am型横按7品)		Em型 5品Am型 5品E型 3品A型 3品
三音和弦
(3-2-1弦)		 5-6-57-8-74-5-35-5-57-6-57-8-75-5-3
💡 注意看三音和弦这一行：F(5-6-5)→G(7-8-7) 上移2品，G→Em(4-5-3) 手型几乎不变只挪一根手指，Dm(7-6-5)→G(7-8-7)→C(5-5-3) 全在 5~8 品打转。整套进行手几乎不用离开 4~8 品区域——这就是三音和弦的威力。

2. 卡农进行 15634125

三百年的旋律机器，前半句"1→5→6→3"下行低音极有叙事感。C 大调：

ⅠC
ⅤG
ⅥAm
ⅢEm
ⅣF
ⅠC
ⅡDm
ⅤG

原型：帕赫贝尔《D大调卡农》。华语抒情大量借用（尤其前半 1563）。

把位：横按版与 4536251 完全相同的那批和弦（C G Am Em F Dm G），只是顺序不同；三音和弦版同样复用上一节的按法。不用学新东西——这就是级数思维的意义。

3. 1564 —— "万能进行"

欧美流行最泛滥的进行，循环到底就是整首歌。C 大调 = C → G → Am → F：

ⅠC
ⅤG
ⅥAm
ⅣF

例：Let It Be（Beatles）、I'm Yours（Jason Mraz）、With or Without You（U2）。

和弦CGAmF
横按 A型 3品E型 3品Em型 5品E型 1品
三音和弦 0-1-00-0-32-1-02-1-1

4. 4615 —— 4536251 的精简版

F → Am → C → G。把虐心进行砍掉经过和弦，留下骨架。副歌想"推情绪"时非常好用。

ⅣF
ⅥAm
ⅠC
ⅤG

和弦全部是老朋友：三音和弦 F 5-6-5 → Am 5-5-5 → C 5-5-3 → G 7-8-7。

🎯 实操练习

1 每天挑一个进行，节拍器 60 BPM，横按版每和弦4拍循环2分钟，三音和弦版循环2分钟。
2 用耳朵验收：手机放一首你怀疑是 4536251 的歌，跟着弹，对了自然"严丝合缝"。
3 四天一轮：D1 = 4536251，D2 = 卡农，D3 = 1564，D4 = 4615 + 1645 混合。

🧠 快速自测

Q1. C 大调里，"4536" 的前两个和弦是：

✓ 4=Ⅳ级=F，5=Ⅴ级=G。级数直接翻译成和弦。
✗ 再想想：4 = 第Ⅳ级 = F，5 = 第Ⅴ级 = G。

Q2. 三音和弦 7-6-5（3-2-1弦）是 C 大调的哪个和弦？

✓ 3弦7品=D，2弦6品=F，1弦5品=A → D-F-A = Dm。查表习惯：指板音名表。
✗ 逐弦查音名：3弦7品=D，2弦6品=F，1弦5品=A → D-F-A = Dm。
