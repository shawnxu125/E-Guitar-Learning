🎸 Lesson 5: 和弦内音与目标音

你需要：电吉他 + 手机（放伴奏）+ 20分钟。前置：Lesson 4 五声音阶把位。

🎯 这节课结束后，你能做到：
  1. 明白为什么"音阶乱跑"不好听、职业乐手在弹什么
  2. 在 1645 的每个和弦上知道该落在哪个音（目标音）
  3. 弹出"跟着和弦走"的 solo 短句——听起来像在说话，而不是在做体操

1. 核心概念：和弦内音（Chord Tones）

为什么有人弹五声音阶像旋律，有人像练手指？区别就一条：

"和弦换了，你的落点音也要换。"
▸ 音阶里的音 = 你可以路过的街道
▸ 和弦内音（根音、3音、5音）= 你落脚的房子
▸ 乐句停在和弦内音上 = 有"回家感"；停在其他音上 = 悬着、没说完

C 大调 1645 的四个和弦，各自的内音是：

和弦内音（根-3-5）其中在 C 五声音阶里的⭐ 首选落点
CC - E - GC E G（全在！）C（根音最稳）
AmA - C - EA C E（全在！）A
FF - A - CA C（F 不在五声音阶里）A 或 C
GG - B - DG D（B 不在五声音阶里）G 或 D
💡 发现了吗：五声音阶"安全"的秘密就在这里——C、Am 两个和弦的内音它全包了；F、G 各缺一个音（F 和 B），但那两个音恰恰是容易撞出紧张感的音。避开它们，怎么弹都不难听。

2. 目标音地图（5品盒子内）

把 Lesson 4 的 5品盒子拿出来，标上四个和弦的落点（音名已逐一核对）：

        C和弦落点(C): 3弦5品 · 1弦8品 · 6弦8品
        Am和弦落点(A): 6弦5品 · 4弦7品 · 1弦5品
        F和弦落点(A或C): 同上两组任选
        G和弦落点(G/D): G=4弦5品 · 2弦8品 / D=5弦5品 · 3弦7品
1 找音游戏：不弹琴，先盯着指板说出每个落点的音名；再逐个按响验证。目标是不用数品格就能直接看到它们。

3. 跟和弦走的 solo 练习

1 手机播放 "C major 1645 backing track"（YouTube/B站都有，每和弦一小节，60-70 BPM）
2 一轮只做一件事：每个和弦的第1拍，准确落在该和弦的目标音上（C→C，Am→A，F→A或C，G→G或D）。其余拍子随便弹盒子里的音。
3 第二轮：目标音改落在第4拍（乐句结尾感更强）。
4 第三轮：每小节弹"2个音+落点"——限制音符数量，强迫你选择。少即是多。
▸ 检验标准：把你的 solo 录下来，只看每小节的第一个音——
▸ 如果它们是 C→A→A/C→G/D 这样"跟着和弦走"的，哪怕其他音乱弹，听感也已经像音乐了。
▸ 这就是职业乐手的第一课：先当狙击手，再当机枪手。

4. 为什么 F 和弦缺 F 音、G 和弦缺 B 音不是问题？

因为落点音不需要是根音——3音和5音同样"在家"。F 和弦上落 A（3音）甚至更有色彩；G 和弦上落 D（5音）非常稳。等你以后学全七声音阶（加回 F 和 B 两个音），选择会更多，但今天的五声落点已经够用一辈子。

🧠 快速自测

Q1. 伴奏进行到 F 和弦时，五声音阶里最适合停下来的音是：

✓ F 和弦内音 = F-A-C，五声音阶里有 A 和 C。
✗ F 和弦 = F+A+C 三个音，其中在五声音阶里的是 A 和 C。

Q2. G 和弦的哪个内音不在 C 大调五声音阶里？

✓ C 大调五声音阶 = C D E G A，没有 B。所以 G 和弦落 G 或 D。
✗ 五声音阶是 C D E G A——G 和 D 都在，唯独 B（G和弦的3音）不在。
